📖 使用手册

      
    

    

      
这个面板是什么

      
本机多账号管家：登记/管理你在本机登录过的 WorkBuddy 账号，看令牌与积分状态、签到领积分、
      一键切换客户端登录的账号。纯本机服务，只监听 127.0.0.1，页面不含任何令牌明文；
      打开它不消耗任何积分——积分只随 AI 对话消耗，面板自己用不花钱。


      
日常怎么打开

      
    
        
  • 书签：浏览器打开 http://127.0.0.1:8765 存为书签，随时点开（首次需带
        ?t=… 的链接打开一次让浏览器记住 cookie）。
    • 
        
  • 开机自启：登录 Windows 后服务自动在后台运行，直接点书签。
    • 
        
  • 打不开时：双击桌面的 WorkBuddy面板.vbs（会自动启动服务并弹出面板），
        或 WorkBuddy面板.url（直接开页面）。
    • 
      


      
账号管理

      
    
        
  • 登记新账号：在客户端登录该号 → 右侧「登记当前账号」填别名 → 点「采集当前登录的账号」。
        多个号就多次登录、多次采集。
    • 
        
  • 改别名 / 归档：账号卡片右下角按钮。归档不是删除，快照移入 trash/，可手工恢复。
    • 
        
  • 令牌状态 / 批量续期：每张卡片可单独看；「全局操作 → 批量续期令牌」一次刷新全部。
        另有计划任务每天 09:00 自动保活。
    • 
      


      
签到与积分

      
    
        
  • 签到领积分：账号卡片上点「签到领积分」（写操作会弹确认），或右侧「全部号依次签到」。
        已签过的当天自动跳过；可顺带派猫猫旅行领奖励。
    • 
        
  • 积分口径：面板显示两个数——
        活动积分(累计)是签到/活动攒的总量；账户积分余额 = 平台奖励剩余 +
        套餐本周期剩余（与客户端账号页一致）。注意套餐的「总量池」不计入，所以不要拿它和别的数字直接相加对比。
    • 
        
  • 余额对不上？积分在实时消耗，面板每次查询都是当下快照。对比时先刷新客户端账号页再看面板。
    • 
        
  • 某号查不到余额：该号可能只有网页会话、没有令牌通道，只能签到、查不到账户余额。
        可点「打开授权窗口」重新登录补全。
    • 
      


      
一键切换客户端账号

      
账号卡片上点「切换到此号」，面板会自动：完全退出客户端 → 写入该号登录态 → 校验 →
      自动重新打开客户端。全程 1~2 分钟，会中断当前 AI 对话，弹窗里强确认后才执行。

      
    
        
  • 同步任务数据：确认弹窗里默认不勾选。勾上才会把当前账号的任务复制一份到目标号
        （复制不是转移，原账号任务保留；定时任务不复制；复制前整库备份）。可在列表里只选部分任务。
    • 
        
  • 记忆不会跟着走：用户级记忆与云端画像按账号分开存放，切换后新账号是空记忆；
        项目目录下的 .workbuddy/memory/ 属于工作区，换号后仍然共享。
    • 
        
  • 已同步过的任务不会二次更新：同一份任务再切一次会被跳过，旧账号后来新增的对话
        不会补到副本里；需要刷新得先清掉同步账本里对应的记录。
    • 
        
  • 切换失败：提示信息会说明卡在哪一步（多为客户端关不掉）。可重试，或终端执行
        python scripts/wb_accounts.py switch <账号id>。
    • 
      


      
常见问题

      
页面提示「无法访问 / 无服务」？
        服务进程不在了。双击桌面 WorkBuddy面板.vbs 重启服务即可；重启电脑后会自动拉起，无需喊 AI（喊了也只多花积分）。

      
积分显示「—」或对不上？
        「—」= 该号没有令牌通道，点「打开授权窗口」登录一次；数值差异多为实时消耗，刷新客户端后再对比。

      
签到按钮灰色？
        当天已签（显示「已签到 ✓」），或该号通道未就绪——按提示先授权。

      
能同时登两个号吗？
        客户端一次只能登一个号；本面板的意义就是把多个号都登记好，切换时不用重新扫码。


      
安全说明

      
只绑 127.0.0.1 + Host 校验 + token/cookie 鉴权，CSP 禁止外部请求；快照与令牌用 Windows DPAPI
      加密落盘，只绑当前用户；网页不接触令牌明文，日志自动脱敏（UID/UIN 打码）。「关闭面板」按钮会优雅停掉后台服务。


      
💬 面板只是本机查看/管理界面。涉及账号登记、令牌修复、终端命令等更深的操作，
      仍可让 AI 助手代劳——但打开面板这件事，用书签就够了。
